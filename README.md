# Site Apple - iPhone 15

Landing page inspirada na apresentação do iPhone 15, desenvolvida com foco em design moderno, responsividade e experiência visual.

## Descrição

Este projeto é uma landing page inspirada na apresentação do iPhone 15, desenvolvida com foco em design moderno, responsividade e experiência visual. A página apresenta uma interface elegante, com seções bem organizadas, elementos visuais atrativos e uso de tecnologias web atuais.

O objetivo do projeto foi praticar a criação de interfaces com React e Tailwind CSS, trabalhando conceitos como componentização, estilização responsiva, organização de layout e publicação do projeto na web.

## Tecnologias utilizadas

- React
- Tailwind CSS
- JavaScript
- HTML
- CSS
- Vite
- Git e GitHub

## Funcionalidades

- Interface inspirada no estilo visual da Apple
- Layout moderno e responsivo
- Componentização com React
- Estilização com Tailwind CSS
- Página de apresentação de produto
- Deploy com GitHub Pages
